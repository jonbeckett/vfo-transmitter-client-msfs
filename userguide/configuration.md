Your settings are saved automatically as you type, and persist between sessions on your Windows user account. You don't need to click a "save" button anywhere.

## Required fields

The Transmitter won't let you connect until these are filled in with your own values (not the placeholder text):

| Field | Description |
|---|---|
| Callsign | Your callsign, e.g. `G-ABCD`. |
| Pilot Name | Your display name, shown to other pilots on the network. |
| Group Name | The group or airline you fly for. |

## Optional fields

| Field | Description |
|---|---|
| MSFS Server | The MSFS multiplayer server region you're connected to, e.g. `WEST EUROPE`. |
| Notes | Free-text notes transmitted alongside your position — visible to others on the network. |
| PIN | An optional PIN, if your server requires one to authenticate transmissions. |
| Server URL | The transmit endpoint the app sends your position to. Defaults to the official VirtualFlight.Online endpoint. |

## Server profiles

The app can remember more than one **server profile** — for example, if you fly on more than one network. Each profile stores its own callsign, pilot name, group, server URL and PIN, so switching profiles switches your whole identity and destination server at once.

## Auto Connect

Turn on **Auto Connect** (File menu) to have the app connect to the simulator automatically every time it starts, instead of needing to click **Connect** manually. See [Using the Transmitter]({% link using-the-transmitter.md %}).

## Resetting your settings

If something looks wrong or you want to start fresh, use **File → Reset Settings to Defaults**. This restores the built-in default server profile and clears any custom profiles you've saved.
